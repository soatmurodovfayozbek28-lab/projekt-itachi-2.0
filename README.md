# Project Itachi 2.0

Xotiraga ega, mustaqil tadqiqot olib boradigan, tahlil qiladigan va egasining rivojlanishiga doimiy yordam beradigan shaxsiy AI agent.

## Holat

Hozirgi bosqich: **1-bosqich — arxitektura va hujjatlar.**
Hali ishlaydigan kod yo'q.

## Modullar (reja)

1. Itachi Core — asosiy boshqaruv
2. Research Engine — tadqiqotchi
3. Mentor Engine — shaxsiy ustoz
4. Business Intelligence — biznes tahlilchisi
5. Memory System — xotira (SQLite + Markdown)
6. Analyst Engine — tahlilchi
7. Strategist Engine — strateg
8. AI Gateway — AI modellar markazi
9. Scheduler — avtomatik boshqaruv
10. Android Interface — telefon ilovasi
